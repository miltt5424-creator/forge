# Forge

Application de discipline personnelle : piliers quotidiens, engagement du matin,
bilan du soir, protocole d'échec, revue hebdomadaire et suivi de constance.

## Stack
TanStack Start · React 19 · Tailwind 4 · Zustand (données locales) · Recharts

## Lancer en local
```bash
npm install
npm run dev      # http://localhost:8080
npm run typecheck
npm run build
```
